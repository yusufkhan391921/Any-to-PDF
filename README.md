AnyToPDF
A simple, private way to turn mixed files into PDFs.
AnyToPDF is an offline file-to-PDF app for Android and the browser. Add one or more files, put them in
the order you want, choose page settings, then create a merged PDF or separate PDFs for each file.
Supported formats
Images: JPG, PNG, WEBP, GIF, BMP, TIFF, SVG
Documents: DOCX, TXT, RTF, HTML, Markdown
Spreadsheets: XLSX, CSV
PDF: merge existing PDF files
Made for your workflow
Preview and reorder files before conversion. Choose A4 or US Letter paper, portrait or landscape
orientation, and page margins. Download one combined PDF or individual PDFs packaged together
when several files are selected.
Private and offline
Conversion happens on the device. The Android app bundles its interface and conversion libraries, does
not require a server or internet connection, and saves finished files locally.
Note: DOCX and XLSX text and tables are converted locally; complex formatting, formulas, and embedded media may not be
preserved exactly.
